# ShitLab (Android)

Elektr shitini yig'ish, PUE bo'yicha tekshirish va ishlash simulyatsiyasi.

- Dastur: `app/src/main/assets/index.html`
- APK har `main` ga push qilinganda GitHub Actions orqali yig'iladi va **Releases** bo'limiga qo'yiladi.
- Android Studio'da ham ochib yig'ish mumkin.

Eslatma: o'quv va dastlabki hisob vositasi. Haqiqiy loyihani litsenziyali muhandis tekshirishi kerak.
