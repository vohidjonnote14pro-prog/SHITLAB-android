# Shit pasporti (Android)

Elektr shiti uchun passport, bir chiziqli sxema va yig'uvchining sifat guvohnomasini PDF qilib chiqaradi. Internetsiz ishlaydi.

- Bu shox (`shit-pasporti`) ShitLab kodidan alohida. ShitLab `main` shoxida.
- Dastur: `app/src/main/assets/index.html`
- APK har `shit-pasporti` shoxiga push qilinganda GitHub Actions orqali yig'iladi va **Releases** bo'limiga `pasport-v1.N` nomi bilan qo'yiladi.

Eslatma: guvohnoma yig'uvchining o'z kafolati, davlat muvofiqlik sertifikati emas.
