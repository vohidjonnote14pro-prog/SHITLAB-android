# ShitLab (Flutter)

Elektr shitlarini PUE bo'yicha loyihalash ilovasi — haqiqiy Android ilova (Flutter).

- Kod: `lib/`
- APK har `flutter` tarmog'iga push qilinganda GitHub Actions orqali yig'iladi va **Releases** bo'limiga qo'yiladi.
- Android qismi (`android/`) yig'ish vaqtida `flutter create` bilan avtomatik yaratiladi; ikonka `branding/` papkasidan olinadi.

## 1-bosqich
Kirish ekrani, loyihalar ro'yxati, yangi shit (8 tur + o'z o'lchami), yuklama hisobi (tok, avtomat, kabel kesimi va markasi, kuchlanish tushishi, UZO, nakonechnik), fazalarni avto taqsimlash, bir chiziqli sxema, telefonga saqlash.

Eslatma: hisoblar PUE qoidalari asosida, lekin yakuniy qarorni elektrik qabul qiladi.
